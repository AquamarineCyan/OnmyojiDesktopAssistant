# GPU 版依赖
# 本文件在 CPU 版基础上引入 Paddle GPU 包，并附带对应的软件源。
# 推荐用法：
#  - 建议使用全新的虚拟环境：python -m venv .venv-gpu && .venv-gpu\Scripts\activate
#  - 使用 pip 安装，并指定 Paddle GPU 的额外源（以 cu129 为例）：
#      pip install -r requirements-gpu.txt --extra-index-url https://www.paddlepaddle.org.cn/packages/stable/cu129/
#  - 或使用 uv：
#      uv pip install -r requirements-gpu.txt -i https://www.paddlepaddle.org.cn/packages/stable/cu129/

# 关于 opencv：此处不声明。cv2 由 paddlex 传递依赖的 opencv-contrib-python 唯一提供，
# 版本跟随 paddlex 的 pin（当前 4.10.0.84），请勿再添加 opencv-python / opencv-python-headless

# 以 extra index 方式加入 Paddle GPU 源，pip 仍会照常查询 PyPI
